# LexiFlash

**📚 Transformez vos documents en cartes de lecture en quelques secondes.**

LexiFlash est une application web libre destinée aux enseignants. Elle permet de créer, organiser et utiliser facilement des corpus de lecture, sans installation et sans création de compte.

## ✨ En un clic

📄 **Importez votre PDF, LexiFlash s’occupe du reste.**

L’application transforme vos cartes de lecture en un corpus prêt à être utilisé.

Elle prend en charge les mises en page de **1, 2, 4 ou 6 cartes par page**.

## Fonctionnalités

- Création de corpus personnalisés
- Import de fichiers texte `.txt`
- Import de fichiers PDF
- Gestion des favoris
- Sauvegarde automatique dans le navigateur
- Aucune installation nécessaire
- Aucun compte à créer

## Essayer LexiFlash

https://lea-app.github.io/lexiflash/

## Données personnelles

Les données restent dans le navigateur de l’utilisateur. Elles ne sont pas envoyées vers un serveur.
